Dokumentasi API Data Maritim BMKG

Informasi API publik untuk prakiraan cuaca maritim, peringatan gelombang, dan produk terkait. Semua endpoint memakai metode GET.

Tentang

API ini memublikasikan setiap berkas di folder sumber dengan path yang sama. Dokumen ini mencakup folder meta/, pelabuhan/, perairan/, doc/cuaca/, warning/, dan wbfs/.

Cara kerja

Base URL
https://maritim.bmkg.go.id/marine2026-data/
Metode
GET

Alur singkat: ambil daftar lokasi dari meta/ → unduh prakiraan dari pelabuhan/ atau perairan/ → unduh produk dari doc/cuaca/ atau warning/.

6 endpoints

https://maritim.bmkg.go.id/marine2026-data/meta/area_province.json

Indeks lokasi dan peta. Berisi daftar wilayah perairan dan pelabuhan per provinsi, plus GeoJSON titik pelabuhan dan poligon wilayah. Tidak berisi prakiraan jam-per-jam.

Parameters

filerequired

Nama berkas di folder meta/. Contoh: area_province.json, port_province.json, pelabuhan.json, wilmetos.min.geojson.

Headers

Tidak ada header autentikasi. CORS diizinkan.

Sample Request

LIVE DEMO!
https://maritim.bmkg.go.id/marine2026-data/meta/area_province.json

forecast_day1 setiap 1 jam (24 titik, 00–23 UTC). forecast_day2-4 setiap 3 jam.

Catatan

  • Data diperbarui berkala (umumnya setelah siklus prakiraan maritim, sekitar 00 UTC).
  • Tidak ada endpoint pencarian. Filter lokasi di klien dari meta/.
  • Hubungkan PDF/PNG di doc/cuaca/ dengan field code pada JSON lokasi.
  • Koordinat GeoJSON: [longitude, latitude] (WGS84).
