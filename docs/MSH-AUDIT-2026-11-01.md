## Clock placement (MSH-relevant)

The live time-zone bar (Delhi → Auckland) lives **inside** the existing `<header class="masthead">` as one flex item inside `city-preferences`. It is a single top band the spatial instrument can see and count — not a `<div>` blind spot (the failure mode documented in docs/CHROME-CENSUS.md). It adds **zero chrome**: masthead stayed 23px phone / 38px desktop. On narrow screens (≤1000px) only the Jakarta local time shows, so nothing wraps or bleeds; desktop keeps the full India→New Zealand range.
